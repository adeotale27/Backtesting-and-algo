How do I get these values?

1. API key / secret — from your Kite Connect app at developers.kite.trade.
2. Access token (fastest) — if you already have one, paste it here.
3. Request token — visit https://kite.zerodha.com/connect/login?v=3&api_key=YOUR_API_KEY, log in with your Zerodha account, and the request_token=… query param on the redirect URL is your one-time token. Paste it here and it will be exchanged for a fresh access token automatically.
